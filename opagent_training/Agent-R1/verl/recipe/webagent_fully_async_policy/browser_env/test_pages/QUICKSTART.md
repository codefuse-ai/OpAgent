## 🐛 故障排查

### 问题: "list index out of range" 错误

**症状**: 
```
WARNING: Attempt 1/5 failed during browser interaction. 
Error: list index out of range. Retrying in 3 seconds...
```

**原因**: 本地 HTML 文件使用 `file://` 协议时，CDP 快照可能返回空的 documents

**✅ 已修复**:
1. `processors.py` 中添加了空列表检查和重试逻辑
2. 测试代码现在使用 HTTP 服务器（端口 8899）而不是 `file://`
3. 增加了超时和重试次数

**如何验证修复**:
```bash
python tool_env.py browser_test
```

应该看到：
```
✓ HTTP 服务器已启动在端口 8899
✓ 加载测试页面成功
```

详细信息请查看 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)

### 问题: "没有可用的浏览器 WebSocket 端点"

**原因**: 环境变量未配置或浏览器未启动

**解决方案**:
```bash
# 检查环境变量
echo $BROWSER_OUTPUT_PATH
echo $TASK_ID

# 检查配置文件是否存在
ls -lh $BROWSER_OUTPUT_PATH/*.json
```

### 问题: 端口 8899 被占用

**症状**: HTTP 服务器启动失败

**解决方案**:
```bash
# 查找占用端口的进程
netstat -tuln | grep 8899
lsof -i :8899

# 终止进程
kill -9 <PID>

# 或者在测试代码中修改端口号
http_port = 8900  # 使用不同端口
```

### 问题: 测试卡住不动

**原因**: 浏览器响应慢或超时

**解决方案**:
- 检查浏览器是否正常运行
- 查看日志中的错误信息
- 尝试重启浏览器
- 增加超时时间（已从 30 秒增加到 120 秒）

### 问题: 截图全是空白或错误

**原因**: 页面加载失败

**解决方案**:
- 确认 test_pages 目录中的 HTML 文件存在
- 检查 HTTP 服务器是否正常启动
- 手动访问 `http://localhost:8899/test_scroll.html` 验证
- 查看浏览器控制台错误
